## Appendix · Formula Sheet and Glossary

### Formulas and rules of thumb

**Air and airspeeds**

| Quantity | Formula or value |
| --- | --- |
| Equation of state | p = ρ R T (R = 287 J/kg/K, T in K) |
| ISA sea level | 1013.25 hPa, 15 °C, ρ0 = 1.225 kg/m³ |
| Dynamic pressure | q = ½ ρ V² = ½ ρ0 EAS² |
| Bernoulli | p + ½ ρ V² = pT (constant) |
| Continuity | ρ A V = constant; A V = constant if incompressible |
| TAS from EAS | TAS = EAS × √(ρ0 / ρ) |
| Speed of sound | a ≈ 38.95 √T kt; 661 kt at ISA MSL, 573 kt at −56.5 °C |
| Mach number | M = TAS / a |

**Lift and drag**

| Quantity | Formula |
| --- | --- |
| Lift | L = CL ½ ρ V² S |
| Drag | D = CD ½ ρ V² S |
| Aspect ratio | A = b² / S |
| Induced drag coefficient | CDi = CL² / (π A e) |
| Parabolic polar | CD = CDP + k CL² |
| CL and speed (level flight) | CL × V² = constant at given W and ρ |
| VMD and mass | VMD ∝ √W |
| VMP | ≈ 0.76 VMD |
| Sweep | effective Mach ≈ M cos Λ |

**Stall and load factor**

| Quantity | Formula |
| --- | --- |
| 1-g stall speed | VS1G = √(2W / (ρ S CLMAX)) |
| Load factor | n = L / W |
| Level turn | n = 1 / cos φ |
| Stall speed with n | VS = VS1G √n |
| Stall speed with mass | VS2 = VS1 √(m2 / m1) |
| Stall speed with CLMAX | VS2 = VS1 √(CLMAX1 / CLMAX2) |
| Manoeuvring speed | VA = VS1G √nlimit; VA2 = VA1 √(m2 / m1) |
| Ultimate load | 1.5 × limit load |
| Buffet margin 1.3 g | bank ≈ 40° |

**Flight mechanics**

| Quantity | Formula |
| --- | --- |
| Climb | T = D + W sin γ; L = W cos γ |
| Climb gradient | sin γ = (T − D) / W ≈ T/W − 1/(L/D) |
| Descent | T = D − W sin γ; L = W cos γ |
| Glide | D = W sin γ; tan γ = 1/(L/D) |
| Glide range | height × L/D (× GS/TAS with wind) |
| Rate of descent | TAS × sin γ |
| Turn | tan φ = V² / (g R) |
| Radius | R = V² / (g tan φ) |
| Rate of turn | ω = V / R = g tan φ / V; rate 1 = 3°/s |
| Rate-1 bank | ≈ TAS (kt) / 10 + 7 |

**Limits and gusts**

| Item | Value |
| --- | --- |
| CS-25 limit load factors | +2.5 (to 3.8) / −1.0; flaps +2.0 / 0 |
| CS-23 normal / utility / aerobatic | +3.8 / −1.52; +4.4 / −1.76; +6.0 / −3.0 |
| Design gusts (EAS) | VB 66 ft/s; VC 50 ft/s; VD 25 ft/s |
| Gust load factor | Δn = ρ0 a Ue VE / (2 W/S) |
| VNE (CS-23) | ≤ 0.9 VD |
| CS-25 speeds | VREF ≥ 1.23 VSR0; V2 ≥ 1.13 VSR; VMC ≤ 1.13 VSR |
| Stall warning | at least 5 kt or 5 % before the stall |
| VMC rudder force | ≤ 150 lbf (667 N); bank ≤ 5° |
| VMCG lateral deviation | ≤ 30 ft (9.1 m) |

**Propellers**

| Quantity | Formula |
| --- | --- |
| Blade angle of attack | blade angle − helix angle |
| Slip | geometric pitch − effective pitch |
| Efficiency | η = thrust × TAS / shaft power |

### Diagram sources

Where possible the diagrams are computed rather than sketched: the flow and pressure picture with an inviscid panel method on a NACA 2412, the drag curve, polar and buffet boundaries from the standard formulas for an aeroplane of A320 size, the V–n diagram from the CS-25 rules, and the propeller curves from a simple blade-element model. Type-specific numbers are illustrative.

- Flow and pressure: J. L. Hess and A. M. O. Smith (1967), panel method; J. D. Anderson, *Fundamentals of Aerodynamics*; NACA Report 824, [Summary of Airfoil Data](https://ntrs.nasa.gov/citations/19930090976).
- Lift curves, polar and drag curve: J. D. Anderson, *Introduction to Flight*; Airbus, [Getting to Grips with Aircraft Performance](https://www.skybrary.aero/sites/default/files/bookshelf/2263.pdf).
- High-lift devices: A. M. O. Smith, *High-Lift Aerodynamics*, Journal of Aircraft (1975); NASA SP-367.
- Transonic flow and shock waves: NASA Glenn Research Center, [Normal shock wave](https://www.grc.nasa.gov/www/k-12/airplane/normal.html).
- Wake turbulence: FAA, [AC 90-23G Aircraft Wake Turbulence](https://www.faa.gov/regulations_policies/advisory_circulars/index.cfm/go/document.information/documentID/1023546); SKYbrary, [Wake Vortex Turbulence](https://skybrary.aero/articles/wake-vortex-turbulence).
- Stall, buffet and upset recovery: SKYbrary, [Stall](https://skybrary.aero/articles/stall); Boeing and Airbus, Airplane Upset Prevention and Recovery Training Aid.
- Envelopes and limits: EASA, [CS-25 Large Aeroplanes](https://www.easa.europa.eu/en/document-library/certification-specifications/group/cs-25-large-aeroplanes) and CS-23.
- Stability and control: B. Etkin and L. D. Reid, *Dynamics of Flight: Stability and Control*; FAA, [Pilot's Handbook of Aeronautical Knowledge](https://www.faa.gov/regulations_policies/handbooks_manuals/aviation/phak) (FAA-H-8083-25).
- Tabs and powered controls: FAA, Aviation Maintenance Technician Handbook – Airframe (FAA-H-8083-31).
- Propellers: B. W. McCormick, *Aerodynamics, Aeronautics and Flight Mechanics*.
