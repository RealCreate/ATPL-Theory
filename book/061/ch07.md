## Appendix · Formula Sheet and Glossary

### Formulas and rules of thumb

**The Earth and the grid**

| Quantity | Formula or value |
| --- | --- |
| Circumference | 21 600 NM ≈ 40 000 km |
| d.lat (NM) | d.lat in minutes |
| Departure (NM) | d.long (') × cos lat |
| New d.long (') | east–west distance (NM) ÷ cos lat |
| Across the pole (d.long 180°) | [(90 − lat A) + (90 − lat B)] × 60 NM |
| Length of a parallel | equator × cos lat |

**Direction**

| Rule | Form |
| --- | --- |
| Compass to true | C → D → M → V → T, add East, subtract West |
| Variation | east, magnetic least; west, magnetic best |
| Track | heading + right drift (− left drift) |
| 1 in 60 track error | off-track × 60 / distance flown |
| 1 in 60 closing angle | off-track × 60 / distance to go |
| Direct to next waypoint | alter by TE + CA |
| Regain track in same distance | alter by 2 × TE |

**Speed and wind**

| Quantity | Formula |
| --- | --- |
| Crosswind | W × sin(angle); clock code 10° ≈ 1/6 … 60° = all |
| Head/tailwind | W × cos(angle) |
| Speed factor | SF = speed / 60 |
| Wind correction angle | WCA = XWC / SF |
| Maximum drift | full wind / SF |
| Effective TAS | TAS × cos WCA |
| TAS rule of thumb | CAS + 2 % per 1000 ft |
| Speed of sound | LSS = 38.95 √T(K) kt; 661 kt ISA MSL; 573 kt at −56.5 °C |
| Mach | M = TAS / LSS |
| Air distance | NAM = NM × TAS / GS |
| Time | min = distance × 60 / GS |

**Climb and descent**

| Quantity | Formula |
| --- | --- |
| Gradient (°) | (height ft / 100) / distance NM |
| Gradient (%) | (height ft / 60) / distance NM |
| Vertical speed | GS × gradient (ft/NM) / 60 |
| ROD on a glide path | angle (°) × GS (NM/min) × 100 = % × GS (kt) |
| ROD on 3° | GS × 5 |
| Descent distance on 3° | ≈ 3 NM per 1000 ft |
| Average TAS and wind | climb: 2/3 of cruise altitude; descent: 1/2 |
| Rate from distance | height × GS / (distance × 60) |

**Great circles, rhumb lines and charts**

| Quantity | Formula |
| --- | --- |
| Earth convergency | d.long × sin mean lat |
| Conversion angle | ½ × d.long × sin mean lat |
| RL track | mean of initial and final GC tracks |
| Constant of the cone | n = sin parallel of origin |
| Chart convergency | d.long × n (Mercator 0, polar 1) |
| Lambert parallel of origin | arcsin(track change / d.long) |
| d.long from track change | (final − initial) / n |
| Scale distance | chart distance × denominator |
| Mercator scale | denominator₂ = denominator₁ × cos lat₂ / cos lat₁ |

**Time**

| Quantity | Value |
| --- | --- |
| Arc to time | 15° = 1 h, 1° = 4 min, 15' = 1 min |
| LMT | UTC + long E, UTC − long W |
| Date line | westbound + 1 day, eastbound − 1 day |
| Sunrise/sunset | upper limb on the horizon (centre ≈ 50' below) |
| Twilight | civil 6°, nautical 12°, astronomical 18° |

### Diagram sources

The diagrams are drawn for study; coastlines come from Natural Earth, and the maps are computed with the projection formulas named below.

- Magnetic variation: NOAA NCEI and BGS, [World Magnetic Model WMM2025](https://www.ncei.noaa.gov/products/world-magnetic-model), evaluated for late 2026.
- Great circles and rhumb lines: Ed Williams, [Aviation Formulary](https://edwilliams.org/avform147.htm); Bowditch, [The American Practical Navigator](https://msi.nga.mil/Publications/APN) (NGA Pub. 9).
- Lambert conformal conic and polar stereographic: J. P. Snyder, [Map Projections: A Working Manual](https://pubs.usgs.gov/publication/pp1395) (USGS Professional Paper 1395).
- Airspeeds: ICAO Doc 7488, Manual of the ICAO Standard Atmosphere; NASA Glenn Research Center, [Speed of sound](https://www.grc.nasa.gov/www/k-12/airplane/sound.html).
- Sunrise, sunset and twilight: US Naval Observatory, [Rise, set and twilight definitions](https://aa.usno.navy.mil/faq/RST_defs).
- Visual navigation and charts: FAA, [Pilot's Handbook of Aeronautical Knowledge](https://www.faa.gov/regulations_policies/handbooks_manuals/aviation/phak) (FAA-H-8083-25), chapter on navigation; ICAO Annex 4, Aeronautical Charts.
- Coastlines: [Natural Earth](https://www.naturalearthdata.com/) 1:110m, public domain.
